## 已实现的测量约束

实现位于 `server/app/g5/measurement.py`；不导入旧 evaluator 或生产 LLM 客户端。

- 六维分别保留：角色策略真实性、认知/知识真实性、时间连续性、互动结构、多人动力学、程序真实性。
- 当前数据契约每维 1–5 分。引用绑定冻结文本的 turn ID 和 Unicode 区间，摘要不能冒充全文证据。
- 评价者身份与种类明确为 synthetic / assistant / ai / human；同一分析只使用一个冻结评价者规格。
  多模型、顺序扰动、重复评价分别形成分析，不把不同评价来源混为一个真值。
- 评分尝试永久保留。技术失败可追加重试；已完成及已判不适用维度不能静默覆盖。
- 未生成、未评分、技术失败、不适用不记作通过。全部分配保留在分母。
- `freeze_labels` 把正负例标签、类别、家族、原文、精确引用、理由及标注工件哈希绑定。
  “human” 是来源声明，不是代码可以认证的真人身份；仍需独立保存实际评审材料。
- 参考正例覆盖合理拒绝、未知、延期、条件同意、异议，当前仅为合成测试控制，不是校准金标集。

## 统计契约及适用范围

四组定义保持 A=C0G0，B=C1G0，C=C0G1，D=C1G1。每个配对块分别估计：

- C 主效应：`(B + D - A - C) / 2`。
- G 主效应：`(C + D - A - B) / 2`。
- 交互：`D - B - C + A`。

先在每个家族内部对完整的四组配对块等权，再对家族等权。不同家族重复数不同不改变
家族总体的目标权重。六维不是六个独立实验样本，不生成总真实性分数。

任一分配评分缺失时，不把完整案例估计冒充全体估计。对确实有定义但缺失的 1–5 分，
给出全体效应的最坏/最好可能范围；它是缺失敏感性界限，不是置信区间。
出现“不适用”时，全体评分效应本身可能无定义，连上述界限也不强行给出。

无缺失且达到预冻结的独立家族门槛时，可做家族级 percentile bootstrap，18 个
维度×效应组合按 Bonferroni 分配名义错误率。重复次数需在调整后的每侧尾部至少提供
20 次抽样分辨率。它是依赖家族可交换/抽样假设的近似区间，不是有限样本覆盖保证。
十个家族是代码的最低门，不是功效分析结果；正式样本量必须由独立先导精度/方差和
实际重要差异论证。测试中的 alpha=.05、差异=.3、20,000 次重采样仅是算法夹具，
**未替未来研究冻结这些数值或证明样本量充足**。

分析契约哈希必须绑定四组共同 evaluator 字段、analysis plan 字段及 sample size plan 字段。
来源/评分工件哈希、阶段和全部尝试一并输出；任何分析都不自动给出“通过资格”结论。
开发数据即使区间排除零也不成为确认性证据。当前尚未完成区间覆盖模拟与真实标注校准。

### 2026-09-11 覆盖反例与新增保守选项

现已完成一个有明确解析界限的离线压力检查，不再把“最低十家族＋足够重采样”理解为
覆盖率验收。合成 IID 家族效应取 0 或 1，出现 1 的概率 .05，真实 C 效应 .05；这可由
合法评分 A=C=2、B=D=2+效应实现。十个家族全部为零的概率为 `.95^10≈.598737`。
此时 percentile bootstrap 必然返回 `[0,0]`，不覆盖 .05，因此其真实覆盖率最多
`1-.95^10≈.401263`，远低于所用 Bonferroni-18 单区间名义覆盖 `.997222`。
增加 bootstrap draws 无法生成未观察到的家族类型。

可复现工件：`G5_SYNTHETIC_COVERAGE_STRESS_20260911.json` 保留最初输出，后续比较另存
`G5_SYNTHETIC_COVERAGE_BOUND_COMPARISON_20260911.json`，不覆盖前者。20 次随机试验的
经验覆盖为 .55、Monte Carlo 标准误约 .111；它与上述长期解析上界不是同一个量，有限
试验比例可以超过该上界。20 次不够做覆盖认证，也不是正式先导或真实模型样本。

新增显式冻结选项 `interval_method="bounded-family-hoeffding-v1"`。独立家族平均效应
的取值界为 C/G 的 `[-4,4]` 和交互的 `[-8,8]`，分别使用范围宽 R=8/16；半径为
`R*sqrt(log(36/alpha)/(2*n))`，并裁至合法效应范围。Hoeffding 双尾界分配 alpha/18，
再对 18 项用 union bound；不依赖观察方差或正态近似，但仍依赖独立、有定义的家族
评分与合理的抽样目标，不能弥补评分者偏差、选择性缺失或相关家族。当前同一 20 次夹具
全部覆盖，仅因区间很宽，不证明研究有精度或检出能力。

旧冻结配置不变，未指定新方法仍保留原 bootstrap；新选项改变 plan 哈希，必须重新
绑定四组共同分析字段。没有追溯修改旧研究结果或为未来真实研究自动选择参数。正式
分析方法/样本量仍需完整冻结及校准；此反例意味着原十家族门不能单独用于确认性区间。

## W4 本地工程范围

`planning.py` 为显式开关 `hierarchical=True` 引入来源约束层级意图：稳定节点、父目标、
先决关系、延期/取消/进展状态。不得删除历史任务或用同 ID 偷换角色/动作/文本；需要改变

执行完成须引用任务创建之后观察到的本角色成功模拟回执；发言任务完成只表示本角色确实
说出了对应原文，不表示议题解决。父目标与子任务状态一致不代表全局任务完成。
跨 episode 保持同一世界/角色记忆边界，跨实验样本或角色复制认知状态被拒绝。
计划引用来源可超出 top-k 保留，但仍只来自本角色已有记忆，旧事实继续标记历史。

长程合成验收覆盖 120 条干扰、事实反转、延迟意图、重建、四组两数据库跨会话和配置隔离。
尚不能据此声称语义检索质量、关系理解、真实模型规划有效或无限长时程可用。
增量计划模式已加入：模型和策略只见开放任务及终态依赖摘要，解析后的原始更新和完整
任务历史都保留；活跃任务容量显式冻结，超限不静默丢弃任务。合成 24 个目标归档后的
上下文保持有界，不代表任意真实文本或无限长公共历史均有界。共同观察窗口现已冻结并
通过四组交付对照：只选最新完整连续后缀，超大最新条目失败而非截断。C1 不额外回填
未交付历史，只保留该角色实际摄取过的内容。窗口可能使角色错过较旧事件，明确给出
省略数量；窗口选择并非已证实最优。原始观察 JSON 字符上限不是全提示/token 上限，
公共投影、事实、存储增长和真实检索质量仍需验收。

## 源密封、独立评价与恢复归档

`freezing.py` 在 SQLite/Postgres 保存不可改写的最终对话回执；只有关闭或达到预算的
世界可显式密封。可重开的 session closure 不自动等同最终密封。密封后公共事件禁止
新增，运行中的候选也不能提交；既有成功重开请求仍可幂等返回，新请求记录 frozen。
密封绑定 manifest、assignment、源事件、规格和绑定哈希，不推断任务成功。

`evaluation.py` 只为已经密封的源生成内部盲评包。模型看到原文、共同世界/角色评审真值
及具体维度 rubric，不看到 arm、ordinal、内部认知/修订/治理审计；原文可能自我暴露，
因此不是完全盲化保证。共同角色真值可能包含私密内容，评价包不是公开全文导出物。
六维评分保留固定模型回执、请求/响应原文和精确引用；技术失败与 N/A 不视为通过。

`evaluation_archive.py` 是独立的本地 SQLite 归档，不迁移源数据库。要求 manifest 的
全部分配各有一个密封包才可建立。头部冻结、评分追加、每次写入事务核对完整历史和
原始响应一致性；同 ID 同内容可恢复确认，已完成/N/A 维度不可被后来写者覆盖。
评分调用在事务外，保存成功后才向消费者确认；重连仅补缺维度，失败历史仍保留。
提供含完整输入/原始评分工件/哈希链的内部导出值。真实进程在事务内退出应回滚，提交后
退出应恢复原记录；不是外部推理 exactly-once 或生产 worker lease。摘要/哈希防意外
改写，不是防拥有数据库写权限者重算全部哈希的密码学身份认证。

目前归档仅为本机 SQLite；没有接入预发批次/服务/API，没有调用真实评价模型。
所有参数、rubric 和评分测试仍是合成夹具，不是正式校准或真实优势结论。

## 完整源工件与离线证据验收

两种源适配器均有 `export_source(world_id)`：SQLite 读事务或 PostgreSQL repeatable-read
只读事务内导出规格/绑定、完整事件含私有认知审计、顺序尝试记录、全部重开输入/终态、
最终密封回执。不导出凭据或数据库物理行号。事件永久密封；尝试及重开元数据只是一个
一致快照，仍可能追加恢复记录，不能冒充所有 worker 已完全静止。

`artifacts.py` 离线重算每条请求哈希、事件链、注册模拟执行器的 effects/可见性，核对
密封与重开成功回执，重放问答与会话投影，可选核对 manifest。`release.py` 再用这些
源重建每个评分输入，与追加式评分导出逐项交叉核对。缺维/技术失败/不适用分别统计；
`evaluation_terminal=true` 只表示评分有终态，`qualification` 始终不自动推断。

证据文件独占创建、0600、fsync、不覆盖旧路径；中断可能留下不完整文件，验证必须失败，
重试用新路径而非覆盖。工具只输出摘要，私密真值、原始对话及认知审计仍属内部工件。
离线命令（仓库根目录，输入为已存在的内部工件，不会执行模型）：

```bash
PYTHONPATH=server .venv312/bin/python -m app.g5.artifacts SOURCE.json --manifest MANIFEST.json
PYTHONPATH=server .venv312/bin/python -m app.g5.release EVIDENCE.json
```

新增全组件观察窗口＋层级计划四组不可用模拟：读取前、策略成功后、提交前切断测试适配器
访问，重新连接/重建后与不中断对照逐事件一致。无法写入时保留的 started 未完成记录不
伪造为失败已落库；不重启用户数据库服务，也不宣称模拟了真实服务崩溃/存储介质损坏。

`acceptance.py` 汇总全部 G5 与契约测试，保存测试身份、失败/跳过、源码前后 SHA-256 和
原始 runner 输出。没有 `--postgres` 与显式测试 DSN 不运行 PostgreSQL；有跳过不能
产生 engineering_checks_passed。该回执不是线上发布批准，剩余发布门仍要逐项验收。
