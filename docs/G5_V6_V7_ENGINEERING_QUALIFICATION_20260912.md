# G5 v6-v7 工程资格测试记录（2026-09-12 至 2026-09-13）

## 结论

G5 的统一结构输出候选最终在源码修订
`f5cd0051aaf761cba4f4154719e510e9379db5ad`通过工程资格测试。该结论只表示运行仪器能够在
固定模型绑定下完成六类结构接口、四个因子臂、16 步截止、故意进程中断和同库恢复；它不构成
评分器有效性、架构效应或研究假设的证据。

最终六接口资格文件的 SHA-256 绑定摘要为
`c9e57547ab17bd7142f0c3d8233320f9abd030ee96ab61d0bd9f6e925aaff0be`。六类接口是策略决策、
反思、层级计划、治理审计、问题标注和会话标注；反思与计划共同保存在 `cognition` 字段中。

最终四臂资格摘要为
`f3a0019b06345d5b2410c664f303f1f091f14278e2328c049471ec13ff1ad5c6`。A、B、C、D 每臂均提交
16 个事件并封存，共 64 个事件、388 条尝试记录和 4 个 freeze。累计第 4 个事件后进程按设计
以状态 75 退出，恢复进程使用同一 binding 和 SQLite 完成余下运行。SQLite
`PRAGMA integrity_check`返回 `ok`，四份 source 均通过 `verify_source`，并逐一匹配 summary 中的
摘要。凭据没有序列化到产物。

最终源码的本地 G5 回归为 403 项通过；48 项 PostgreSQL 测试因本机没有该服务而跳过。远端
针对性层级计划、统一结构输出和 v7 绑定测试 14 项通过。

## 最终修复的含义

v7 没有放松任务完成证据。执行任务仍必须引用任务创建后、同一角色、同一操作且成功的模拟回执；
发言、询问和拒绝任务仍必须引用任务创建后该角色自己的精确公开发言。改动只把校验器已经掌握的
信息以机器可读形式反馈给模型：可直接复制的不可变任务字段、当前状态、逐任务可用于完成的来源、
终态任务 ID、新任务允许的初始状态，以及父目标在当前候选计划中的必需状态。

## 研究阶段边界

这些批次全部标记为 `synthetic-engineering-only` 和
`must_not_enter_development_or_confirmatory_evidence`。没有运行评分器、没有计算四臂效果，也没有
启动 8 条开发验证。下一步应以已通过资格的精确运行修订冻结 8 条开发执行绑定；是否提交包含
内部拒绝响应与 SQLite 的资格归档、以及是否启动 8 条开发对话，应分别记录授权。
