`panel.json` 保留共同冻结 manifest、分析计划、4份完整源工件、密封评价输入、8个独立
评分归档及描述性诊断。完整源包含内部角色真值，不得作为公开转录发布。

- 控制：紧凑/缩进 JSON × 确定性打散后的正/反顺序 × 2次重复，共8格。
- 每格：4份源对话 × 6个维度，共24次评分；总计192次。重复评分不是新增独立对话。
- 字符串原文、turn ID、引文Unicode位置、上下文与rubric不改变，仅JSON布局不同。
- 预先注入的合成偏差：紧凑格式得4分，缩进格式得5分。72行配对诊断正确检出格式
  差1分，顺序和重复对照差0分。以上都是脚本规定的结果，不是实测模型偏差。
- 每个维度单独报告配对完整数、未配对数、平均带符号差/绝对差与精确一致率；不输出
  显著性结论、不合并成总分，不把评分次数用于家族样本量。
